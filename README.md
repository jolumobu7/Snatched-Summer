# Snatched by Summer

Website for the Snatched by Summer app (GitHub Pages).

- `index.html` home page
- `privacy.html` privacy policy (linked from the App Store and Google Play listings)
- `support.html` help and contact (support URL for the stores)
- `app/` web version of the app (built from the app repo with `npx expo export --platform web --output-dir app`)
- `classic/` the original Snatched Summer web tool
- `.nojekyll` required so GitHub Pages serves the `app/_expo` folder
